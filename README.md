# Notes Scratchpad

A clean, distraction-free browser notes scratchpad for quick markdown and plain text drafts.

## Features

- **Auto-Save:** Automatic persistence to browser `localStorage` on every keystroke.
- **Character & Word Counter:** Real-time text statistics.
- **Export:** One-click download of notes as plain `.txt` or `.md` files.

## Tech Stack

- Vanilla JavaScript
- HTML5 & CSS3

## Run

Open `index.html` in any browser.
